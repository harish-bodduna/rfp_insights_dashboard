# RFP Insights Dashboard

Simple UI to manage RFP/RFQ uploads, trigger the processing pipeline, and review extracted traits from the `rfp_analyzer` backend.

## Prerequisites

- Node.js 20+
- Running instance of the FastAPI backend (defaults to `http://localhost:8000`)

## Getting Started

```bash
cd /home/stormy/dev-workspace/rfp_insights_dashboard
cp env.example .env.local   # create if needed
npm install
npm run dev
```

Add the backend URL to `.env.local` (or `.env`) so the dashboard knows where to send requests:

```
VITE_API_BASE_URL=http://localhost:8000
```

## Available Commands

| Command         | Description                            |
| --------------- | -------------------------------------- |
| `npm run dev`   | Start the Vite dev server              |
| `npm run build` | Type-check and produce production JS   |
| `npm run lint`  | Run ESLint (if configured in the repo) |

## Features

- Upload PDF with optional metadata notes (`POST /documents/`)
- View queued uploads and trigger Celery processing (`POST /documents/{id}/process`)
- Browse completed documents and inspect all traits with evidence snippets
- Export the currently displayed trait table as CSV
- Scrollable table with sticky headers for large trait sets
# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
